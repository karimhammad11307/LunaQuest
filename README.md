# Moonbound: Survival Mission

Repository preparation for a child-friendly lunar survival game. The current branch contains the typed domain contract, centralized game configuration and a partial pure survival-rule foundation. The React entry point is a bootstrap only; gameplay scenes have not been implemented.

## Run

```sh
npm install
npm run dev
```

## Verify

```sh
npm run build
npm test
```

Current status and next MVP stages are in [docs/HANDOFF.md](docs/HANDOFF.md). The previous Mars Commander prototype is preserved on `backup/mars-commander-codex`.
